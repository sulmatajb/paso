# Paso privacy

Paso keeps guest learning records in your browser. Signing in creates a separate local account record and enables cloud synchronization on this deployment. Bringing guest progress into an account requires choosing **Add my guest progress**. Signing out leaves the local copy on your device; use your browser's site-data controls to remove local records and downloaded models.

Synced records include lesson answers and attempts, review schedules, settings, placement answers/results, conversation messages, and timestamps. The account screen displays the identity supplied by the sign-in provider. Server records are keyed by the provider's stable user ID. There is no public profile, leaderboard, advertising SDK, or analytics SDK.

With on-device speech recognition, microphone recordings stay in memory on the device and Whisper processes them locally. If the host enables server recognition, the recording control discloses this before use: a short mono WAV is uploaded through the authenticated Paso route to the configured speech service. The bundled service processes it in memory without writing recordings to disk or logging them. Recordings are never included in progress synchronization. You can replay a recording while its screen is open. Only transcripts you confirm are saved. Server recognition needs an internet connection.

Local Qwen and Kokoro inference does not send conversation text to model publishers. Downloading models contacts Hugging Face and the pinned WebLLM library host. If the deployment operator configures a hosted model, the interface identifies that mode: conversation text and text to be spoken are sent through the Paso server to the configured inference service. Its operator controls that service's retention policy. The bundled self-hosted speech service does not log request text or audio.

When **Community server** mode is enabled, your browser instead sends short recordings, recent conversation text, and text to synthesize directly to the operator's public Hugging Face Space. Models run there; your phone does not download model weights. Gradio temporarily stores uploaded and generated audio, with periodic cleanup enabled. The app adds no training, analytics, or persistent conversation database to the Space, but Hugging Face controls infrastructure logs and retention. Recordings are not included in Paso account synchronization. Review and confirm the transcript before sending it to the conversation model. Do not put private information into the public demo.

Paso calls the community Space without an owner API token. Requests from Paso use Hugging Face's anonymous allowance; a Hugging Face login in another tab is not automatically applied to these requests. The interface links to the standalone Space, where a signed-in learner can use their own free allowance. Queues and daily limits apply. The app never buys inference credits or switches to paid inference when a limit is reached.

Browser caches can be evicted. Unsynced work is lost if you clear site data. Export your learning record from Settings or Account for a readable JSON copy. File restore is not yet supported. Account synchronization is not end-to-end encryption; the deployment operator controls the server database. To request deletion of server-side records, contact the operator of your deployment; there is currently no in-app account deletion workflow. Signing out is not deletion.
